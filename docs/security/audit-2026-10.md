# Security and privacy audit — October 2026 — findings

Companion to [`PLAN.md`](PLAN.md) (method, inventory, decisions) and
[`README.md`](README.md) (the plain-words guide). This file is the record:
every finding, how it was reproduced, what fixed it, and the test that keeps
it fixed.

**Public-repository rule:** no secret values, no personal data, no
transcripts. Reproductions quote commands and *shapes* of output; any token,
PIN or row value is `<redacted>`.

## Conventions

- **Ids** `SEC-NNN` — assigned in `PLAN.md`, stable forever. Gaps are fine.
- **Severity** Critical / High / Medium / Low / Info — defined in `PLAN.md`
  § Severity scale.
- **Status** `hypothesis` → `verified` | `unverified` | `false-positive` |
  `accepted` → `fixed` (names the commit and the test).
- **Door** the route, page, file or process the finding lives in.
- **Reproduction** was run against the local dev server on `:3101`
  (`npm run dev -- --port 3101`, empty `pitaya_lane_a` database, `.env.local`
  with `APP_PIN` and random secrets) unless it says `script` (a node script
  under `scripts/` or an inline test) or `prod-readonly` (an
  unauthenticated GET/POST against the public URL, no credentials, no
  writes). Cookie login for local smoke:
  `curl -s -c /tmp/lane-a.jar -H 'content-type: application/json' -d '{"pin":"<redacted>"}' http://localhost:3101/api/auth`.
