A — PEN-POSITIONED
Compact, icons only, rises beside the tip on the free-hand side so the palm never covers it. Best when the pen is already down; fades if the pen leaves hover.
B — FIXED UPPER-RIGHT
Labelled, always in the same place in the pane header — predictable, finger-friendly, never over text. Best for finger selections and long sessions.
