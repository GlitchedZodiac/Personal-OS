HOW IT GETS DATA — ENGINEERING NOTE
The launcher's .never was a constraint choice, not an oversight — free personal teams make app-group containers fragile, so the widget shares nothing with the app. Round 1 assumes the widget extension fetches the bearer API itself (sequences + week summary), caches last-good to its own container, and reloads on:
· midnight (due/rotation flips)
· WidgetCenter.reloadAll() after every app sync
· offline → last cache + an "as of Tue" line, never a blank
